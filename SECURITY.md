# Security policy

Report vulnerabilities privately through GitHub Security Advisories. Do not include third-party target data, credentials, cookies, tokens, client identities, or unredacted evidence.

In scope: scope bypasses, permission mistakes, unsafe installer behavior, path traversal, SQL injection into the local state database, evidence integrity problems, and instructions that could trigger unapproved activity.

This project is for systems you own or are explicitly authorized to assess. If authorization or scope is uncertain, stop active work.
